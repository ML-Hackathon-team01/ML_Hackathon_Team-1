
# PathSnap

PathSnap is a machine learning-based GPS map-matching project.
It aims to match noisy GPS observations to the correct road segments
in a road network.

## Team Model Assignments

- Navya: Logistic Regression and SVM
- Neal: Decision Tree
- Sohel: Gradient Boosting
- Shreyas: Random Forest

## Project Workflow

1. Data inspection
2. Data cleaning
3. Candidate road generation
4. Feature extraction
5. Label preparation
6. ML dataset preparation
7. Model training
8. Evaluation and comparison

## Project Structure

- data_inspection: Inspecting and checking dataset files
- preprocessing: Cleaning data and preparing datasets
- features: Feature extraction
- models: Individual ML models
- results: Generated outputs
- notebooks: Experiments

## Dataset

The dataset is maintained separately and is not included
in this code repository.

## Status

Preprocessing pipeline is under development.
Current candidate labels are preliminary and require
improvement before final model evaluation.
